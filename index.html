About VoicePilot

VoicePilot is a desktop voice-assistant project developed with Python. It combines speech recognition, automation, and text-to-speech to make common computer tasks easier to perform.

Technology Stack

🐍 Python SpeechRecognition PyAutoGUI pyttsx3 PyAudio

How It Works

  1. Speak: Give a supported voice command.
  2. Recognize: Speech recognition processes the command.
  3. Execute: Python runs the corresponding action.
  4. Respond: The assistant provides feedback.

Example commands: “Open Notepad,” “Search Google for Python,” and “Volume up.”
